# Changelog

## 0.1.0-beta

First public beta.

* Visual shortcut editor: ~120 generic blocks, variables you name, nested If / Repeat / Menu, drag and drop,
  input and output shown on every block, in-app help.
* Import of unsigned Apple `.shortcut` files and export to `.shortcut`.
* Automations: time, charger, battery, Wi‑Fi, Bluetooth, airplane mode, NFC tag.
* Run from the home screen, widget, quick-settings tile and the Android share menu.
* Plugins: add blocks with one JSON file.
* System blocks: Do Not Disturb, ringer mode; Wi‑Fi, Bluetooth, mobile data and airplane mode through Shizuku.
* Light, dark and system themes; English, Français, Italiano, Deutsch and Español.

Known limits: shortcuts signed by Apple cannot be read yet; exported files are unsigned; the Gallery tab is a placeholder.
